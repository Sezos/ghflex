How the AI meter works

What counts as "AI"?

A commit counts as AI-assisted if it carries an AI co-author trailer (Claude Code, Copilot, Cursor, Aider…) or was made by an AI agent account. Inline autocomplete leaves no trace in git, so it's never counted. The number is a floor, not a guess.
